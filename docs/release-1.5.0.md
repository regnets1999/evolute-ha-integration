# Evolute 1.5.0

Первый выпуск форка `regnets1999/evolute-ha-integration` на базе оригинального v1.4.3. Целевая платформа — Home Assistant 2026.11 и новее.

Для перехода с оригинала дождитесь публикации релиза, подготовьте откат и создайте свежий backup VM100 в Proxmox непосредственно перед чистой установкой. Версия 1.5.0 создаёт устройства и сущности с локальными UUID. Старые `entity_id` не мигрируют. После настройки обновите ссылки в автоматизациях и дашбордах. [Установка и откат](marketplace.md#переход-с-исходного-репозитория)

## Исправления

- После настройки и повторной авторизации сохраняется актуальная пара токенов. При повторной авторизации остальные поля записи сохраняются.
- Параллельные запросы с устаревшей парой используют один refresh. Запоздалый запрос может повториться с уже обновлёнными токенами.
- Сетевые ошибки, тайм-ауты и некорректные ответы обрабатываются отдельно от подтверждённого отказа авторизации. При сбое отдельного автомобиля опрос сохраняет результаты по остальным.
- Повторная авторизация проверяет совпадение аккаунта. Новая настройка использует стабильный идентификатор аккаунта и блокирует подтверждённые дубликаты, включая записи со старым `unique_id`.
- В carV2 отсутствие серверных флагов аккаунта больше не скрывает подготовку к поездке, если она доступна по телеметрии автомобиля.
- Идентификаторы устройств и сущностей строятся из локальных UUID. Названия устройств используют модель и постоянный локальный номер. VIN исключён из новых имён и атрибутов.

Домен `evolute` сохранён. [Условия сохранения новых идентификаторов](compatibility.md)
