# Публикация форка в Marketplace

Home Assistant 2026.11 включает Marketplace, который использует `hacs.json` в корне репозитория. Форк содержит одну интеграцию в `custom_components/evolute/`. В этом каталоге находятся `manifest.json`, модули, переводы и ресурсы Lovelace. Версия поставляется из архива GitHub, отдельный ZIP-ассет не требуется. [Структура репозитория](https://contributors.home-assistant.io/marketplace/reference/repository-structure/) · [Схема `hacs.json`](https://contributors.home-assistant.io/marketplace/reference/hacs-json/)

## Версия и выпуск

- Версия форка — `1.5.0`. После отдельного согласования тег стабильного GitHub Release должен быть `1.5.0`, как в `manifest.json`. Это SemVer с приоритетом выше оригинального `v1.4.3`. Для следующих исправлений форка подходит ряд `1.5.1`, `1.5.2` и далее. Репозиторий указывает, какой проект выпустил версию.
- `homeassistant: 2026.11.0` в `hacs.json` задаёт нижнюю границу целевого выпуска. Marketplace проверяет её для репозитория с GitHub Releases. Без опубликованного релиза пользовательский репозиторий может предлагать текущий коммит ветки по умолчанию.
- `CARD_VERSION` относится к кэшу JavaScript-карточки. Поскольку ресурс карточки не менялся, в этой подготовке его значение сохранено.
- Текст для GitHub Release подготовлен в [описании версии 1.5.0](release-1.5.0.md). [Правила выпуска Marketplace](https://contributors.home-assistant.io/marketplace/guides/releases/)

## Добавление по ссылке и общий каталог

Публичный форк предназначен для добавления по ссылке в Marketplace. Для установки на чистой системе после выпуска проверьте, что открыта карточка `regnets1999/evolute-ha-integration` и выбран нужный релиз. Локальные проверки структуры и тесты не заменяют пробную установку на Home Assistant.

Общий каталог требует отдельной заявки в `hacs/default`. На 12 ноября 2026 года у форка есть описание и включены GitHub Issues. Для подачи заявки остаются topics, опубликованный GitHub Release, успешные проверки HACS и hassfest и значок `brand/icon.png` либо подтверждённый бренд домена в реестре Home Assistant. В дереве форка и в проверенных каталогах брендов значка нет. [Требования каталога](https://contributors.home-assistant.io/marketplace/guides/catalog/)

## Переход с исходного репозитория

Marketplace 2026.11 блокирует установку репозитория, если тот же домен уже принадлежит другому установленному репозиторию. Безопасная смена владельца с `dsultanr/evolute-ha-integration` на отдельный форк без удаления `ConfigEntry` не подтверждена. [Проверка владельца в Core 2026.11.1](https://github.com/home-assistant/core/blob/2026.11.1/homeassistant/components/marketplace/repositories/integration.py#L154-L171)

Версия 1.5.0 использует локальные UUID. Старые устройства, сущности и `entity_id` не мигрируют. [Совместимость идентификаторов](compatibility.md)

1. Завершите проверки и после отдельного согласования опубликуйте стабильный GitHub Release `1.5.0`. Убедитесь, что опубликован именно релиз форка.
2. Подготовьте окно обслуживания и откат. Проверьте доступ к Proxmox и доступность хранилища резервных копий. Сохраните список используемых `entity_id` и связанных автоматизаций, скриптов и дашбордов.
3. Непосредственно перед установкой, до удаления исходной записи, создайте свежий backup **VM100** в Proxmox. Убедитесь, что задание завершилось успешно и копия доступна для восстановления. [Резервное копирование и восстановление в Proxmox VE](https://pve.proxmox.com/pve-docs/chapter-vzdump.html)
4. В Home Assistant откройте **Настройки → Устройства и службы** и удалите конфигурационную запись оригинального Evolute 1.4.3.
5. Удалите пакет `dsultanr/evolute-ha-integration` через **Настройки → Marketplace**. Если Home Assistant предложит удалить пакет сразу после удаления записи, подтвердите и проверьте, что исходный пакет больше не установлен. [Удаление пакетов Marketplace](https://www.home-assistant.io/integrations/marketplace/#uninstalling-content)
6. В Marketplace выберите **Add from link** и добавьте `https://github.com/regnets1999/evolute-ha-integration`.
7. На карточке форка установите именно `1.5.0`, выполните предложенный Home Assistant перезапуск и заново настройте Evolute.
8. Проверьте, что Marketplace показывает `1.5.0` как установленную версию репозитория `regnets1999/evolute-ha-integration`. Проверьте устройства и телеметрию, затем обновите ссылки на новые `entity_id` и проверьте связанные автоматизации и дашборды.

### Откат

Если чистая установка или проверка не удались и нужно вернуть прежнюю запись вместе с реестрами, восстановите VM100 из свежего backup, созданного перед переходом. Откат возвращает состояние всей VM на момент резервного копирования. После запуска проверьте исходный пакет Evolute, запись, устройства и автоматизации. [Восстановление в Proxmox VE](https://pve.proxmox.com/pve-docs/chapter-vzdump.html)

Если сохранение старых `entity_id` обязательно, отложите переход на 1.5.0 до появления согласованной миграции. Ручная замена каталога с сохранением `ConfigEntry` также использует новую схему идентификаторов.
