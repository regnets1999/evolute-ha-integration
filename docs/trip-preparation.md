# Подготовка к поездке

[`EvoluteClient._async_update_user_flags()`](../custom_components/evolute/client.py) по-прежнему запрашивает флаги аккаунта. После успешного ответа клиент оставляет `_tagged_buttons_visible` равным `True`. Пустой объект или отсутствие `isSuperAdmin` и `canViewTaggedCarButtons` в ответе больше не скрывает состояние подготовки и само по себе не блокирует её кнопки в Home Assistant. Обработка HTTP-ошибок запроса флагов остаётся прежней.

Для carV2 `_parse_car_info_v2()` читает `enabled` и `status` кнопки `tripPreparationOn` из `buttons[]`. Интеграция использует их для состояния подготовки и разрешает `PREPARE`, когда кнопка включена и сценарий простаивает, а `CANCEL` — когда сценарий выполняется. Проверки паркинга, доступности автомобиля и центрального замка продолжают применяться. Имена команд carV2 берутся из `activateCommand` и `deactivateCommand`, а результат отправки определяется ответом Evolute.

Для legacy tbox состояние по-прежнему берётся из `preparation_script`. Логика отправки команд и обработки телеметрии legacy не менялась.
